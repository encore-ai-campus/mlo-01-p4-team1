이 디렉터리는 공통 문서 소유 영역입니다. 두 개발 작업자는 설계도나 파일 소유권을 개별적으로 수정하지 않고 [공통 변경 절차](../handoff/infra/OWNERSHIP.md)를 따릅니다.
