# 핏플레이스 손님용 매장 탐색 프런트엔드

카페와 주점을 찾는 손님용 화면의 디자인과 구현 기준입니다. 이 문서는 현재 작업 화면을 설명하며 전체 서비스의 API 명세를 대체하지 않습니다.

## 디자인 기준

- 글꼴: Pretendard Regular(400), SemiBold(600), Bold(700). 글꼴 파일과 라이선스는 `public/fonts/`에 있습니다.
- 주색 `#FF383E`, 보조색 `#FF7775`, 배경 `#FAF8F5`, 카드 `#FFFFFF`.
- 기본 글자 `#242424`, 보조 글자 `#77736F`, 연한 강조 배경 `#FFF0EF`, 테두리 `#E8E4E0`. 주색 또는 보조색으로 채운 요소에는 `#FFF0EF` 글자를 사용합니다.
- 데스크톱에서는 지도와 매장 목록을 나란히 배치하고 화면이 좁아지면 세로로 배치합니다. 767px 이하에서는 모바일용 간격과 전체 너비 상세 드로어를 적용합니다.
- 지역 선택 목록은 흰색 바탕과 연한 빨간색 선택 상태를 사용하며 키보드 조작을 지원합니다. 필터와 매장 카드에는 호버 및 선택 상태를 표시합니다.
- 디자인 기준은 Figma의 01 데스크톱 탐색, 02 모바일 탐색, 03 상세 드로어, 04 토큰과 컴포넌트입니다. PNG 시안은 GitHub에 포함되지 않습니다. 디자인 참고 자료는 Figma에서 확인하세요.

## 화면과 데이터

화면 코드는 `src/features/venues/`에 있으며 필터, 매장 카드, 지도, 상세 드로어로 구성됩니다. 기존 API 응답을 사용합니다. 실제 표시 데이터는 실행 환경에 따라 달라지며, 로컬 샘플에는 예시 또는 대체 메뉴가 포함될 수 있어 실제 매장 정보로 검증된 값이라고 가정하지 않습니다.

자체 평점이 연결되기 전에는 평점 준비 중으로 표시합니다. 지도에 전달된 유효한 기온이 없다면 기온 정보 없음으로 표시합니다. 지도를 이동한 뒤 이 지역 재검색을 선택하면 해당 범위를 검색합니다. 날씨 선택과 추천 등 기존 동작은 현재 연결된 데이터 및 실행 환경에 따릅니다.

## 로컬 실행

명령은 저장소 루트에서 시작합니다.

백엔드 환경과 프런트 의존성이 설치된 상태에서 각각 별도 터미널을 사용합니다. 포트가 사용 중이면 다른 포트를 선택하고 프런트의 대상 주소도 함께 바꿉니다.

```sh
cd app
C_LOCAL_DEMO=1 .venv/bin/python -m backend.manage runserver 127.0.0.1:8002 --noreload
```

```sh
cd app/frontend
VITE_RECOMMENDATION_API_TARGET=http://127.0.0.1:8002 npm run dev
```

Vite가 출력하는 로컬 주소에 `/venues`를 붙여 접속합니다. 위 명령은 손님용 화면의 로컬 시연 모드입니다. `PLATFORM_LOCAL_MVP=1`을 추가하면 통합 모드로 실행되며 로그인과 손님 권한이 필요하고 일부 시연용 쓰기 API는 비활성화됩니다. 최초 설치 및 추가 설정은 각 구성 요소의 설정 파일과 프로젝트 문서를 확인하세요.
