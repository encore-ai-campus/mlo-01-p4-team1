# 핏플레이스 손님용 매장 탐색 frontend

카페와 주점을 찾는 손님용 화면의 디자인과 구현 기준입니다. 이 문서는 현재 작업 화면을 설명하며 전체 서비스의 API 명세를 대체하지 않습니다.

## 디자인 기준

서비스별 현재 화면 규칙과 반응형 배치는 다음 문서를 참고하세요.

- [핏플레이스 프론트엔드 규칙서](./docs/핏플레이스_프론트엔드_규칙서.md)
- [뮤더 프론트엔드 규칙서](./docs/뮤더_프론트엔드_규칙서.md)

## 화면과 데이터

화면 코드는 `src/features/venues/`에 있으며 필터, 매장 카드, 지도, 상세 드로어로 구성됩니다. 기존 API 응답을 사용합니다. 실제 표시 데이터는 실행 환경에 따라 달라지며, 로컬 샘플에는 예시 또는 대체 메뉴가 포함될 수 있어 실제 매장 정보로 검증된 값이라고 가정하지 않습니다.

자체 평점이 연결되기 전에는 평점 준비 중으로 표시합니다. 지도를 이동한 뒤 이 지역 재검색을 선택하면 해당 범위를 검색합니다. 지역 날씨와 추천 결과는 연결된 데이터 및 실행 환경에 따릅니다.

## 로컬 실행

명령은 저장소 루트에서 시작합니다.

백엔드 환경과 프런트 의존성이 설치된 상태에서 각각 별도 터미널을 사용합니다. 포트가 사용 중이면 다른 포트를 선택하고 프런트의 대상 주소도 함께 바꿉니다.

```sh
cd app
C_LOCAL_DEMO=1 .venv/bin/python -m backend.manage runserver 127.0.0.1:8002 --noreload
```

```sh
cd app/frontend
VITE_RECOMMENDATION_API_TARGET=http://127.0.0.1:8002 npm run dev
```

Vite가 출력하는 로컬 주소에 `/venues`를 붙여 접속합니다. 위 명령은 손님용 화면의 로컬 시연 모드입니다. `PLATFORM_LOCAL_MVP=1`을 추가하면 통합 모드로 실행되며 로그인과 손님 권한이 필요하고 일부 시연용 쓰기 API는 비활성화됩니다. 최초 설치 및 추가 설정은 각 구성 요소의 설정 파일과 프로젝트 문서를 확인하세요.
