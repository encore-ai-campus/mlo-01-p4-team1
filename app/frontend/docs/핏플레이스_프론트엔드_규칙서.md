# 핏플레이스 매장 탐색 프런트엔드 규칙서

기준일: 2026-11-12. 손님용 `/venues` (및 통합 `/platform/consumer`) 화면의 현재 코드 기준이다. 구현된 상태를 기록한 문서이며, 운영 정책 확정이나 브라우저·실제 데이터 검증 완료를 뜻하지 않는다. CSS에 같은 선택자의 이전 선언이 남아 있으므로 수정할 때는 뒤쪽의 덮어쓰기와 미디어 쿼리를 함께 확인한다.

## 범위와 주요 파일

- 화면 구성: `../src/features/venues/pages/VenueExplorePage.tsx`
- 탐색 화면 스타일: `../src/features/venues/venue-design.css`
- 상세 화면 스타일: `../src/features/venues/components/venue-detail.css`
- 검색·필터, 지도, 매장 카드와 상세 화면: `../src/features/venues/components/`
- 기존 Figma 참고: [일반 사용자용 반응형 웹](https://www.figma.com/design/XHhuX2MeHzcn5Bz5AhdceW/), 01 데스크톱 탐색, 02 모바일 탐색, 03 상세 드로어, 04 토큰과 컴포넌트. 현재 코드와 차이가 있을 수 있으므로 구현 상태는 코드를 기준으로 확인한다.
- 별도로 공유된 [새 모바일 디자인](https://www.figma.com/design/Z5RLhMmjRf6gVPZQG5cJsS/)은 위 기존 시안과 다른 파일이다. 이 규칙서만으로 새 디자인이 구현에 반영됐다고 판단하지 않는다.

## 공통 디자인

- 글꼴은 Pretendard이며 Regular 400, SemiBold 600, Bold 700 글꼴 파일을 사용한다. 기본 글자는 15px/24px, 400이다.
- 주요 색상: 빨강 `#FF383E`, 보조 빨강 `#FF7775`, 흰색 `#FFFFFF`, 기본 글자 `#242424`, 보조 글자 `#77736F`, 테두리 `#E8E4E0`, 연한 강조 배경 `#FFF0EF`. 요소에 따라 별도 색상도 사용한다.
- 키보드 조작 시 `:focus-visible`로 초점을 표시한다. 마우스 클릭 상태와 키보드 초점 표시는 구분한다.

## 전체 배치와 반응형

| 화면 폭 | 현재 배치 |
| --- | --- |
| 901px 이상 | 왼쪽에 광고 틀과 검색·목록, 오른쪽에 지도. 두 열의 간격 24px. 지도는 상단에서 110px 지점에 sticky로 고정된다. |
| 900px 이하 | 광고 틀 → 지도 → 검색·필터·매장 목록 순서로 한 열에 배치한다. 간격은 18px이며 지도는 문서 흐름을 따른다. |
| 601~900px | 지도 프레임 높이 360px. |
| 600px 이하 | 지도 프레임 높이 300px. 상단 문구는 14px. |
| 768px 이하 | 매장 상세 드로어가 화면 너비를 채운다. |

901px 이상에서 지도 높이는 `calc(100vh - 134px)`, 최소 높이는 440px이다. 상단 바가 있는 화면의 본문 상단 여백은 기본 110px, 767px 이하에서는 80px이다. 화면 전체 좌우 여백은 기본 24px, 900px 이하 16px, 600px 이하 14px이다.

## 상단 바와 메뉴

- 흰색 상단 바는 화면 상단에 `fixed`로 배치한다. 최소 높이 64px, 내부 좌우 여백은 기본 24px, 767px 이하는 16px이다. 실제 높이는 콘텐츠에 따라 늘어날 수 있다.
- 로고와 ‘나에게 딱 맞는 하루’, 알림, 마이페이지, 전체 메뉴 버튼을 표시한다. 알림·마이페이지는 아이콘으로 표시한다.
- 전체 메뉴 순서는 관련 서비스(`itda` · `muther`), 사장님 페이지, 로그인이다. 사장님 페이지 하위에는 매장 음악 관리, 사장님 등록, 이벤트 발행이 있다.
- 알림·마이페이지 등의 팝오버는 바깥 영역을 클릭하면 닫히도록 구현되어 있다. 표시 여부는 화면 모드·사용자 상태에 따라 달라질 수 있다.

## 광고 틀

- 탐색 화면 소개 문구 바로 위에 배치하고 검색 영역과 너비를 맞춘다. 900px 이하에서는 지도 위에 표시한다.
- 너비 100%, 높이 110px, 모서리 16px, 배경 `#F0F1F2`. ‘광고 배너 영역’ 문구는 16px이고 가로·세로 중앙에 놓인다.
- 현재는 자리 표시용 틀이다. 실제 광고 소재, 광고 API, 클릭·노출 측정은 `/venues`의 이 틀에 연결되어 있지 않다. 음악 추천 화면의 상·하단 광고와 별개다.

## 소개와 검색 필터

- 소개 문구는 ‘내 주변의 새로운 발견’, ‘{지역}의 카페와 주점’, ‘오늘의 취향에 맞는 장소를 찾아보세요.’ 순서다. 제목은 기본 26px, 600px 이하에서 23px이다.
- 필터 배경은 `#F7F8FA`, 내부 여백 기본 20px, 767px 이하 16px이다. 지역, 검색 결과 수, 날씨, 검색어와 필터를 표시한다.
- 날씨는 사용자가 선택하지 않고 선택 지역의 관측 정보를 조회한다. 지역 목록에서 일치하는 첫 항목을 찾고 날씨를 요청하며, 30초마다 갱신을 시도한다. 테스트 데이터, 오래되거나 누락된 현재 데이터, 강수 정보가 없는 경우에는 현재 날씨로 표시하지 않는다. 로딩 중과 조회 불가 상태를 구분하며 실제 데이터 제공 여부는 실행 환경에 따른다.
- 빠른 필터: 이벤트 진행 중, 추천 음악 큐레이션, 영업 중. 나머지는 업종, 금액, 형태다. 일반 음식점은 준비 중으로 비활성화되어 있다.
- 현재 `추천 음악 큐레이션` 필터의 백엔드 조건은 제휴 매장이거나 추천 스타일 정보가 있는 매장을 포함한다. 표시명과 이 조건이 의도한 운영 정책인지 별도 확인이 필요하다.
- 업종·금액·형태 라벨은 400 굵기이며 항목과 세로 중앙을 맞춘다. 항목은 줄바꿈하지 않고 영역 안에서 가로로 스크롤한다. 스크롤바는 숨긴다.
- 선택된 칩은 연한 강조 배경과 투명 테두리를 사용한다. 지역 목록은 키보드 조작과 선택 상태를 지원한다.

## 지도와 매장 목록

- 지도에는 매장 위치, ‘이 지역 재검색’, 확대·축소, 내 위치 버튼이 있다. 재검색 버튼에는 별도 화살표가 없다. 사용자가 지도를 이동하면 새 범위를 대기 상태로 보관하고 버튼을 눌렀을 때 검색에 적용한다. 대기 중인 범위가 없으면 버튼은 비활성화된다.
- 지역 선택이 바뀌면 결과 좌표 또는 지역 중심을 기준으로 지도 화면을 이동한다. 내 위치는 브라우저 위치 권한과 사용 가능 여부에 따라 실패할 수 있으며 오류 안내를 표시한다.
- 확대·축소 버튼 각각과 내 위치 버튼은 44×44px이며 오른쪽 기준선을 맞춘다. 지도 저작자 표시는 별도로 존재한다.
- 매장 카드는 흰색 바탕과 둥근 모서리, 기본 테두리를 사용하며 포인터를 올리면 빨간 테두리와 그림자가 나타난다. 검색 결과 및 상세 내용은 API와 실행 환경에 따라 달라진다.
- 사진 트랙은 가로 스크롤이며 기본 사진 크기는 115×115px이다. 대표 사진을 먼저 두고 나머지 사진을 이어 붙이며, 중복 URL과 유효하지 않은 URL을 제외한다. 사진이 없으면 사진 영역을 표시하지 않는다. 로딩 중에는 안내를 표시하고, 실패하거나 30초가 지나면 오류와 재시도 버튼을 표시한다.
- 메뉴 미리보기는 제공된 항목을 가로로 나열하고 좌우 버튼 또는 스크롤로 넘긴다. **메뉴 미리보기 항목**의 너비는 기본적으로 트랙의 약 1/3, 767px 이하에서는 약 2/3이다. 이는 매장 카드 전체의 너비가 아니다. 메뉴 데이터가 없으면 해당 미리보기 영역을 표시하지 않는다.
- 매장 카드에는 영업 상태, 제휴 매장(`is_partner`)인 경우 `제휴 매장` 배지, 1인 가격과 `평점 준비 중`을 표시한다. 이는 개별 리뷰 별점과 구분되는 매장 전체 평점 표시다. 음악 배너는 매장 상세 화면의 표시 조건을 따른다.

## 추천과 매장 상세

- ‘나에게 맞는 장소 추천받기’는 접고 펼칠 수 있으며 제목 옆에 빨간 테두리의 AI 추천 배지가 있다. 일부 추천 기능은 환경 설정과 읽기 전용 여부에 따라 달라진다.
- 추천 로딩의 최소 대기 시간은 요청별 300~600ms이며, 실제 요청이 더 오래 걸리면 완료 또는 오류까지 기다린다.
- 매장 상세는 오른쪽에서 열리는 드로어다. 선택한 상단 탭은 연한 배경을 사용하며 테두리는 투명하다. 하단 찜하기·지도에서 보기 버튼의 내용은 가운데 정렬한다.
- 매장 전체 평점은 `자체 평점 준비 중`으로 안내한다. 개별 리뷰 점수는 0~5 범위로 반올림한 개수의 별 이미지로 표시하며, 리뷰가 없으면 안내 문구를 표시한다. 전체 평점 집계가 실제 연결되었다는 뜻은 아니다.
- 데이터의 `music_banner.has_music_banner`가 참일 때 상세 음악 배너를 표시한다. 이는 실제 재생 연동 여부의 독립적인 검증을 보장하지 않는다.
- 이벤트 홍보 배너는 선택 지역에 활성 이벤트가 있을 때 추천 영역에 표시된다. 여러 이벤트는 4.5초마다 전환되며, 이벤트가 없거나 조회에 실패하면 표시하지 않는다. 유료 광고와 동일하다고 가정하지 않는다.

## 화면 모드와 데이터

- 읽기 전용 모드에서는 추천 영역과 매장 카드의 찜 기능을 표시하지 않는다. 상세 화면에서도 리뷰 작성 등 일부 참여·수정 기능이 제한된다. 화면 상단 바의 표시와 로그인 안내는 호출 방식과 계정 상태에 따라 달라진다.
- 공개자료로 확인한 매장은 일반 매장과 다른 상세 정보를 사용하며, 제공되는 경우 대표 메뉴·주문 예시·확인 일자와 출처 링크를 표시한다. 리뷰 작성과 찜 등은 일반 매장과 표시 조건이 다르다.
- 로컬 시연 데이터에는 예시 또는 대체 메뉴가 포함될 수 있다. 위치·영업 상태·날씨·음악·추천 결과는 연결된 API 및 실행 환경에 따라 달라진다. 일부 사진 로딩 실패와 매장별 메뉴의 실제 일치 여부는 별도 검증이 필요하다.
- 코드상 규격은 실제 브라우저 크기, 기기, 데이터 상태에서 별도로 확인해야 한다. 작성·참여 기능의 성공 및 오류 처리도 실제 연동 상태를 별도 점검한다. 실행 및 검사 명령은 [프런트엔드 README](../README.md)를 참고한다.
