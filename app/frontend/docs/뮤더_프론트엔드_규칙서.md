# 뮤더 프론트엔드 규칙서

기준일: 2026-11-11. 현재 `frontend-workspace`의 로컬 구현을 기준으로 정리했다. 미커밋 변경을 포함하며, GitHub 반영이나 모든 기기·데이터 환경에서의 검증 완료를 뜻하지 않는다. 화면 및 정책이 바뀌면 코드와 함께 이 문서를 갱신한다.

## 범위와 구현 위치

| 구분 | 경로 | 주요 구현 |
| --- | --- | --- |
| 홈 | `/` | `src/features/recommendation/PublicPage.tsx`, `HeroBanner.tsx`, `MoodGallery.tsx` |
| 오늘의 선곡 | `/playlist` | `PublicPage.tsx`, `PlaylistIntro.tsx`, `src/features/music-options/` |
| 로그인 | `/login` | `src/features/admin/AdminPages.tsx`의 `Login` |
| 회원가입 | `/signup` | `src/features/accounts/Accounts.tsx`의 `Signup` |
| 계정 찾기 | `/account/recovery` | `Accounts.tsx`의 `Recovery` |
| 헤더 | 홈·선곡·회원 화면 | `src/components/Header.tsx`, `header-brand.css` |
| 날씨·지역 | 홈·선곡 | `src/features/region-weather/WeatherPanel.tsx`, `RegionPicker.tsx` |
| 공통 스타일 | 화면별 적용 | `src/muther-home.css`, `src/style.css`, `src/features/accounts/accounts.css` |

`src/main.tsx`의 `PlatformAlias` 및 실행 설정에 따라 회원 화면과 매장 탐색이 플랫폼 경로로 연결될 수 있다. 뮤더 자체 화면과 `/platform/`의 통합 회원 화면을 같은 구현으로 간주하지 않는다.

## 공통 색상과 글꼴

- 뮤더 주색상은 `#BFDCEE`이며 `--muther-primary`로 선언한다. 홈·선곡의 주요 버튼과 일부 선택·강조 요소, 로그인·회원가입 등의 주요 버튼에 사용한다. 밝은 버튼의 글자에는 어두운 색을 사용한다.
- Figma 공통 로그인 기준 주요 글자는 `#222222`, 보조 설명·입력 안내는 `#666B70`을 지정한 영역에서 사용한다. 기존 세부 요소와 상태에는 별도 색상이 남아 있으므로 전체 텍스트가 동일한 색상이라고 간주하지 않는다.
- `TODAY'S PLAYLIST`, 홈의 `WEATHER × MUSIC`, `MADE FOR YOUR DAY`, 회원 화면의 `MUSIC X WEATHER` 캡션은 `#5C8294`를 사용한다. 다른 영문 캡션에 자동으로 적용되는 규칙은 아니다.
- 선곡 화면의 날씨 반영·보컬·빠르기 라디오 버튼 선택색은 기존 파란색 `#087BF1`을 유지한다.
- Pretendard는 **홈 화면에만 시범 적용**되어 있다. `public/fonts/`의 Regular 400, SemiBold 600, Bold 700 파일을 사용한다. 선곡·회원 화면 전체에 Pretendard가 확정 적용된 상태는 아니다. 나머지 뮤더 본문은 `Inter`, `Pretendard`, `Noto Sans KR`, 시스템 글꼴 순서이며 일부 로고·장식에는 Arial이 지정되어 있다.
- 폰트 라이선스는 `public/fonts/OFL.txt`를 확인한다. 브라우저와 설치된 글꼴에 따라 기존 화면의 실제 폰트가 달라질 수 있다.

## 헤더와 반응형

- 헤더의 뮤더 로고는 `public/muther-wordmark.png`를 사용하고, 아래에 ‘오늘의 날씨를 들어보세요’를 표시한다. 로고 파일과 헤더 코드는 함께 관리한다.
- 일반 헤더에는 홈, 오늘의 선곡, 카페·주점 탐색, 사용 안내, 로그인 또는 마이페이지가 있다. 플랫폼 사용 가능 여부에 따라 메인 플랫폼 링크와 계정 이동 경로가 달라진다.
- 로그인용 헤더에는 뮤더 로고와 선곡 페이지로 돌아가는 링크가 있다. 홈·선곡 화면의 외부 컨테이너 상단 여백은 0이다.
- 화면 폭 1100px 이하에서 일부 헤더·날씨 배치를 조정하고, 950px 이하에서 헤더와 날씨 영역을 재배치한다. 700px 이하에서는 모바일 헤더, 축소 여백과 한 열 선곡 화면을 사용한다. 세부 값은 `muther-home.css`, `header-brand.css`의 미디어 쿼리를 기준으로 한다.
- 버튼과 링크는 키보드 초점 표시를 제공한다. 상태를 색상만으로 구분하지 않도록 기존 레이블과 비활성 상태를 유지한다.

## 홈 화면

상단 광고 영역 다음에 오늘의 선곡표 소개와 선곡 화면으로 이동하는 버튼, 지역·날씨 패널, 날씨별 분위기 카드와 필터, 선곡 화면으로 이동하는 하단 영역을 표시한다. 하단 광고 영역도 있다.

날씨 카드의 맑음·노을·비·흐림·눈·밤은 분위기 미리보기이며, 실제 선곡 결과로 확정해 표시하지 않는다. 지역을 선택하지 않거나 날씨를 불러오지 못한 상태에는 해당 안내를 표시한다. 실제 날씨와 광고 데이터는 실행 환경에 따라 달라진다.

## 오늘의 선곡 화면

- 소개 영역에는 ‘오늘의 선곡을 / 시작해 볼까요?’를 같은 제목 색상으로 표시하고, 선택 지역과 날씨 상태를 보여준다.
- 날씨 반영 여부, 보컬, 빠르기, 테마·장르를 선택한 뒤 선곡표를 요청한다. 지역을 선택하지 않으면 날씨 미반영으로 진행할 수 있다.
- 데스크톱에는 음악 선택, 음악 재생, 선곡표를 나란히 배치한다. 화면 폭이 줄어들면 열 수를 줄이고 모바일에는 세로로 배치한다.
- 요청 중·오류·선곡 전·조건 변경·승인 등 기존 상태와 버튼의 활성 조건을 유지한다. 곡 정보, 재생 가능 여부 및 추천 결과는 API와 데이터 상태에 따른다.
- YouTube 사전 준비와 연결의 기술적 범위는 [다음 곡 사전 준비 문서](../src/features/recommendation/PLAYBACK_PRELOAD.md)를 참고한다. 해당 문서에 있는 별도 연결 기능이 현재 화면에 자동 적용됐다고 가정하지 않는다.

## 회원 화면

- 로그인: 아이디, 비밀번호, 로그인 유지, 회원가입·계정 찾기 등 기존 진입점과 오류 안내를 유지한다.
- 회원가입: 아이디 중복 확인, 비밀번호·확인, 선택 별명, 약관·안내·연령 확인, 선택 복구 이메일을 제공한다. 검증 정책과 사용 가능 상태는 `src/shared/accountPolicy.ts` 및 서버 응답을 따른다.
- 계정 찾기: 아이디 찾기 또는 비밀번호 재설정을 선택하고 확인된 복구 이메일로 안내를 요청한다. 복구 링크에 따라 아이디 확인이나 비밀번호 재설정 화면이 표시된다.
- 회원가입과 계정 찾기 기본 화면 배경은 로그인 화면과 같은 `radial-gradient(ellipse at 50% 30%, #f5faff 0%, #fff 65%)`를 사용한다. 복구 링크 화면까지 동일하게 적용된다고 가정하지 않는다.
- 정책, 메일 발송, 로그인·세션 등은 연결된 백엔드와 실행 설정에 영향을 받는다. 로컬 안내 문구를 운영 정책 확정으로 취급하지 않는다.

## 확인과 변경 관리

- `muther-home.css`, `style.css`, `accounts.css`에는 이전 선언과 뒤쪽의 덮어쓰기가 공존한다. 새 규칙을 추가하기 전에 선택자 우선순위, 적용 범위, 미디어 쿼리를 함께 확인한다.
- 이미지 위 텍스트, 밝은 주색상 위 글자, 선택·비활성 상태는 실제 브라우저에서 대비와 가독성을 확인한다. 홈의 Pretendard 시범 적용은 모바일과 선곡·회원 화면으로 확대하기 전에 별도로 확인한다.
- 화면별 동작은 로컬 및 백엔드 설정에 따라 확인하고, 오류·빈 결과·로딩 상태도 점검한다. 디자인 변경 이후 프론트엔드 빌드와 관련 테스트를 실행한다.
- [핏플레이스 프론트엔드 규칙서](./핏플레이스_프론트엔드_규칙서.md)는 별도 문서로 유지한다. 공통 헤더·계정 동작을 변경할 때는 두 서비스에 미치는 영향을 함께 확인한다.
